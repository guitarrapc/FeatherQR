    About the playground

    This playground is a static page: after the WASM runtime loads, FeatherQR encodes and renders every QR code in your browser. Nothing you type is uploaded to a server.

    • Rendering uses the real SkiaSharp (Skia) native library compiled to WebAssembly, the output is pixel-identical to what the NuGet package produces on .NET.
    • Share link stores your settings compressed in the URL hash. Uploaded logo images are not included in share links.
    • Decorated codes (gradients, shapes, logos) trade error margin for looks, always test-scan before printing.
    • Every generated code is decoded back in-browser by the library's own decoder as a self-check, and the Decode an image panel reads QR codes from your image files the same way.
    • The Photograph the code panel prints the code on a simulated card and photographs it, tilted, through a lens, blurred, noisy or unevenly lit, to find where a design stops reading.
    • GS1 data is checked and converted by the FeatherQR.Gs1 package, whose application identifier table is generated from the GS1 Syntax Dictionary under the Apache License 2.0. See the third-party notices.
